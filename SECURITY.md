# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability or routing exploit vector, please do NOT open a public GitHub issue.

Please report vulnerabilities directly via:
- **Telegram:** [Arbitrage Inception Telegram](https://t.me/ArbitrageInception)

### Scope
- Python telemetry and route evaluation logic (`scanner.py`)
- Anti-phantom pool check (`verify_kyber_executable`)
