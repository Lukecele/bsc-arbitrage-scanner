# Contributing to BSC Arbitrage Scanner

We welcome open-source contributions to expand supported DEX aggregator APIs, optimize token evaluation concurrency, and refine slippage diagnostics.

## How to Contribute
1. Fork the repository.
2. Create a feature branch: `git checkout -b feat/your-feature`.
3. Test your changes locally: `python scanner.py`.
4. Open a Pull Request with a clear description.
